START 
    INPUT array[], n( current count), pos(position), newValue;

    FOR i FROM n-1 DOWN TO pos DO
        SET array [i + 1] = array[i]
    END FOR

    SET array[pos] = newValue;

    PRINT inserted successfully

END

time complexity the loop shifts elements one by one;
therefor time complexity is O(n)
space complexity 0(1) no extra arry is created
